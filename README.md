# Catálogo de piezas coleccionables

Programa de consola en Python para gestionar un catálogo básico de piezas
coleccionables (reto Python nivel II).

## Estructura

```
catalogo_coleccionables/
├── catalog.py        -> Funciones del catálogo
├── validations.py    -> Funciones de validación
├── main.py           -> Menú y flujo principal
└── README.md
```

## Cómo ejecutar

```
python main.py
```
